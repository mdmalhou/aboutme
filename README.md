# Mohamed Malhou — Research website

A concise personal research website built as a dependency-free static site for GitHub Pages.

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

In the repository settings, open **Pages**, choose **Deploy from a branch**, and select the
repository's default branch and `/ (root)` folder. The site will be available at:

`https://mdmalhou.github.io/aboutme/`
